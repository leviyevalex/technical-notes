# Technical Notes

A blog for mathematics, algorithms, and quantitative finance, written in org-mode and published with Hugo.

## Stack

| Layer | Tool |
|---|---|
| Authoring | Org-mode + [ox-hugo](https://ox-hugo.scripter.co/) |
| Site generator | [Hugo](https://gohugo.io/) |
| Theme | [hugo-bearcub](https://github.com/clente/hugo-bearcub) |
| Math rendering | [MathJax 3](https://www.mathjax.org/) |
| Figure rendering | pdflatex + [mutool](https://mupdf.com/) |

## Prerequisites

```bash
brew install hugo mupdf-tools
```

Doom Emacs with `(package! ox-hugo)` in `packages.el`.

## Local development

```bash
# Clone with theme submodule
git clone --recurse-submodules <repo-url>
cd blog

# Pre-render tikz and algorithm figures to SVG
bash render-figures.sh

# Export org posts to Hugo markdown (in Emacs)
# Open posts.org → C-c C-e H H

# Serve locally
cd site && hugo server
```

## Adding a post

Each top-level heading in `posts.org` is one blog post. Add a subtree:

```org
* My Post Title
:PROPERTIES:
:EXPORT_FILE_NAME: my-post
:EXPORT_DATE: 2026-06-04
:END:

Content here. Math works inline $e^{i\pi} + 1 = 0$ and display:

\begin{equation}
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
\label{eq:gaussian}
\end{equation}
```

Export with `C-c C-e H H` in Emacs.

## Adding a figure

1. Create a standalone LaTeX file in `figures/src/name.tex`
2. Run `bash render-figures.sh` to produce `site/static/figures/name.svg`
3. Reference in a post with:

```markdown
{{< figure src="/figures/name.svg" caption="My caption." >}}
```

## Equation cross-references

Use `\begin{equation}...\label{eq:foo}...\end{equation}` for numbered equations.
Reference with `\eqref{eq:foo}` in plain text (no dollar signs).

## Project structure

```
posts.org               ← all blog posts as org subtrees
setup-blog.org          ← shared org export settings
render-figures.sh       ← renders figures/src/*.tex → site/static/figures/*.svg
figures/src/            ← standalone LaTeX sources for tikz and algorithm figures
site/                   ← Hugo site
  content/posts/        ← generated by ox-hugo (do not edit manually)
  static/figures/       ← pre-rendered SVGs
  layouts/              ← theme overrides (KaTeX/MathJax, theorem CSS)
  themes/hugo-bearcub/  ← theme (git submodule)
```
