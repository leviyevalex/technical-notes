A random walk is a stochastic process that models a particle moving randomly through space. It arises naturally in physics (Brownian motion), finance (stock prices), and combinatorics.

* Definition

#+begin_definition
A *symmetric random walk* on $\mathbb{Z}$ is a process $(X_n)_{n \geq 0}$ with $X_0 = 0$ and i.i.d. increments $\xi_k$ satisfying
$$P(\xi_k = +1) = P(\xi_k = -1) = \tfrac{1}{2}.$$
#+end_definition

* The optional stopping theorem

#+begin_theorem
Let $T = \min\{n \geq 0 : X_n \notin (-N, N)\}$. Then $E[T] = N^2 - X_0^2$ and
$$P(X_T = N \mid X_0 = x) = \frac{x + N}{2N}.$$
#+end_theorem

* Recurrence

#+begin_theorem
The symmetric random walk on $\mathbb{Z}$ is *recurrent*: starting from any position, it returns to that position with probability 1.
#+end_theorem

#+begin_proof
By Stirling's approximation, the return probability at time $2n$ satisfies
$$p_{2n} = \binom{2n}{n} \frac{1}{4^n} \sim \frac{1}{\sqrt{\pi n}},$$
and since $\sum_{n=1}^{\infty} p_{2n} = \infty$, return is certain by the second Borel-Cantelli lemma.
#+end_proof

#+begin_remark
Recurrence fails in three or more dimensions: the symmetric random walk on $\mathbb{Z}^d$ is transient for $d \geq 3$.
#+end_remark
