## Deployment

Push to `main` → GitHub Actions runs `hugo --minify` → deploys to GitHub Pages. No manual build step needed.

## Switching hosts

`baseURL` in `hugo.toml` is the **only value that needs to change** when switching hosts. The figure shortcode reads `Site.BaseURL` dynamically — no other files need updating.

To keep `hugo.toml` host-agnostic, set `baseURL = "/"` and pass the real URL at build time:
```yaml
- run: hugo --minify --baseURL "https://newhost.com/"
```

## Figure shortcode params

`layouts/shortcodes/figure.html` accepts:

| Param | Source | Purpose |
|---|---|---|
| `src` | export pipeline | SVG path, prefixed with `Site.BaseURL` to handle subpath deployment |
| `caption` | `#+CAPTION:` in org | `<figcaption>` text; JS prepends "Figure N:" at runtime |
| `id` | `#+NAME:` in org | Set as `id=` on `<figure>` so `\cref{fig:...}` can resolve it |

**Why we override Hugo's built-in:** Hugo's default uses root-relative URLs that break under a subpath `baseURL`. The `id=` passthrough for cross-references also requires a custom param the built-in doesn't support.

## Subpath URL trick

The site is served at `/technical-notes/` (a subpath), so absolute paths like `/figures/foo.svg` resolve to the wrong location. `layouts/shortcodes/figure.html` handles this by stripping the leading `/` and prepending `Site.BaseURL`:

```html
{{ printf "%s%s" (printf "%s" .Site.BaseURL) (.Get "src" | strings.TrimPrefix "/") }}
```

This works correctly for root domains, subpaths, and local dev with no code changes.

## Theorem environments and cross-references

Theorem environments (`theorem`, `lemma`, `proposition`, `corollary`, `definition`, `remark`, `note`, `proof`) are styled as left-border divs via CSS in `static/css/style.css` (light) and `custom_head.html` (dark).

**Runtime JS** (`static/js/math-refs.js`, loaded via `custom_head.html`) runs three passes on `DOMContentLoaded`:
1. Numbers all environments with a shared per-section counter (format: `TypeName {section}.{counter}`) — injects a `<strong class="env-label">` as the first child and sets `data-numbered` to suppress the CSS `::before` fallback
2. Prefixes figure captions with "Figure N:"
3. Walks all text nodes and replaces `\cref{id}` / `\Cref{id}` with `<a class="cref-link">` links

To test the JS in isolation: open `static/js/math-refs.test.html` directly in a browser — all assertions should show PASS.

**CSS class conventions** — do not rename without updating both `publish-to-hugo.el` and `math-refs.js`:

| Class / attribute | Set by | Purpose |
|---|---|---|
| `data-name="..."` | `publish-to-hugo.el` advice on `org-hugo-special-block` | Display name from `#+begin_theorem Name` |
| `data-numbered` | `math-refs.js` | Suppresses CSS `::before` once JS has injected `.env-label` |
| `.env-label` | `math-refs.js` | `<strong>` carrying the full numbered label |
| `.cref-link` | `math-refs.js` | Applied to `<a>` elements from `\cref{}` resolution |
| `.unpublished-ref` | `publish-to-hugo.el` | Greyed-out span for denote links to notes not yet exported |

## Content pipeline

Content in `content/` is **generated by ox-hugo — do not edit `.md` files directly**.

### From blog-src (existing posts)

```bash
cd ~/Documents/org/blog-src
bash export.sh          # export only modified files
bash export.sh --all    # force re-export everything
bash export.sh post.org # export single file
```

`export.sh` auto-triggers `render-figures.sh` (LaTeX → SVG into `static/figures/`) and uses a single Emacs batch session with a sentinel file (`.last-export`) to skip unchanged files.

### From Denote notes (~/Documents/org/technical/)

Use `SPC n B` (`M-x my/publish-to-hugo`) in Doom Emacs from any Denote org buffer. This command:
1. Finds every `\begin{tikzpicture}` and `\begin{algorithm}` block
2. Renders each to SVG via pdflatex → mutool, stored in `static/figures/<denote-id>/`
3. Names SVGs from `#+NAME: fig:partial-sums` → `partial-sums.svg`, or falls back to `tikz-N` / `algo-N`
4. Exports to `content/posts/` via ox-hugo in a temp buffer
5. **Original org file is never modified**

Defined in `~/.config/doom/publish-to-hugo.el`, loaded from `config.el`.

## Known workarounds

### tabular tables → SVG via preview package

`\begin{tabular}` blocks (including when wrapped in `\begin{center}`) are rendered to SVG by `publish-to-hugo.el`. They use `\documentclass{article}` + `\usepackage[active,tightpage]{preview}` rather than `standalone`, because `standalone` boxes its content and `\begin{center}` (which uses `trivlist` internally) throws "missing \item" inside that box. The `preview` approach matches what `org-latex-preview` uses and compiles reliably.

### org-compat.elc / "Invalid function: org-export-with-buffer-copy"

`org-export-with-buffer-copy` is a macro in `ox.el`, but straight.el compiles
`org-compat.el` before `ox.el` (alphabetical order), so the macro never gets
expanded in `org-compat.elc` — it sits there as a runtime function call and
throws "Invalid function" at export time.

Fix in `~/.config/doom/config.el`: an `(after! ox ...)` block that recompiles
`org-compat.el` (with ox now in scope) and immediately reloads the new `.elc`.
Runs once per session on first ox load. See config.el for the exact code.
